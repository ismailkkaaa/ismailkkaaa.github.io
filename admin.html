Static CMS Workflow

Portfolio Admin Panel

This admin panel behaves like a mini CMS without a backend. Your content is saved in localStorage under portfolioData, so refreshes keep your work until you export JSON.

View Portfolio
1Add or edit content in any section
2Changes autosave to localStorage
3Copy the generated JSON into data.json

File selection is only for preview and filename detection. After selecting an image, manually place that file into poster/, reels/, or projects/.
